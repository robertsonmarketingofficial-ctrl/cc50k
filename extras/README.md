# Extras

Standalone copies of the interactive pages built alongside the email system. The live versions are
Claude artifacts. Open these files in a browser; they need an internet connection for fonts and 3D.

| File | Live page | What it is |
|---|---|---|
| `robertson-vault.html` | https://claude.ai/artifact/JRpC32R9Ze5Z7Y5Ee2jF5S | Obsidian-style graph of your notes. Notes live in the artifact's storage, so this local copy shows an empty vault; use the live page. |
| `messines-mine-cutaway.html` | https://claude.ai/artifact/Vp6zm6NNzeGJyR81B6PVu2 | 3D cutaway of the Spanbroekmolen mine (Messines, 1917) with an adjustable explosion |
| `etude-cs-minor.html` | https://claude.ai/artifact/GD3syN6oASJJvH8SLMHE9M | Original Chopin-style étude played on an 88-key piano |
